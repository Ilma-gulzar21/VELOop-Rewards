# VELOop Rewards Frontend

This folder contains the React + Vite client for VELOop Rewards.

## Setup

```bash
npm install
```

Create a local `.env` file from `.env.example` and set the backend API URL:

```env
VITE_API_URL=http://localhost:5000/api
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

See the root `README.md` for complete backend, database, Super Admin, and project setup instructions.
